# Ganesh Anil Patil Books — Starter Frontend

A responsive static frontend starter for an author/book website.

## Files
- `index.html` — page structure and sample book catalogue
- `styles.css` — responsive visual design, mobile navigation, dark mode
- `app.js` — search/filter, language toggle, details modal, dark mode

## Current working features
- Responsive layout for phone and desktop
- Hindi/English interface toggle for main interface copy
- Search by title, genre and language; genre/language filters
- Book details modal
- Dark mode toggle
- Mobile bottom navigation
- Sample newsletter form (demo only; does not send/store emails)

## Important limitations
This is the first frontend prototype. The admin panel, secure login, database, cloud uploads, real book/chapter content, newsletter delivery, backup automation and live analytics are not connected yet. Do not put secrets or passwords in these static files. A backend service must be configured before any real admin access or personal-data collection.

## Preview locally
Open `index.html` in a modern browser. For GitHub Pages, upload all three website files to the root of a repository and enable Pages in repository settings.
